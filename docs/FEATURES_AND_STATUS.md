# Features and status

| Area | Current source | Evidence / qualification |
| --- | --- | --- |
| Shift and hold controls | PROJ modifier, track/launch/mixer shortcuts | Earlier device use; later fixes vary by version |
| Drum sequencing | Step locks, conditions, Euclidean generation | Existing public foundation with subsequent fixes |
| Drum synthesis | Kick, Snare, Hi-hat, Clap, Tom/FM percussion | Multiple engines and revisions; not a separate general-purpose FM synth |
| Analog/subtractive synthesis | Oscillators, filter, modulation, sync-related work | Analog has been reported working; all combinations not hardware-certified |
| Modulation | Native drum destinations; MOD/MATRIX access | MOD/MATRIX reported working in P16; later labels added |
| Melodic locks | Two note-owned locks; supported envelopes and sends | Track-type and routing limits in KNOWN_ISSUES |
| Performance | Tempo/key/pads/chord controls | Separate from experimental macro strip |
| Navigation | SEQ view tabs, Undo, note navigation | P20 tab display and melodic Euclid playback confirmed; subsequent fixes still version-specific |
| Chord editing | Position, length, insertion, chord selection and Clear | Reworked after device reports; later behaviour needs further verification |
| Track FX | EQ, compressor, soft clipper | Predates this publication; preview redesign is separate |
| Macros / motion | Implementations present | Broken/incomplete on latest reported hardware |
| Design kit | Interactive visual studies and reusable renderer | No firmware screen replacement; native label gaps documented |
