# Development status — 26 October 2026

The public source snapshot deliberately stops at **P27 / 1.6P27**. Later macro reworks and the arpeggiator are excluded. This is an experimental source publication, not a stable firmware release.

P27 startup and project loading were confirmed on hardware, as was opening/closing the macro strip with horizontal swipes. Parameter mapping failed and the sample instrument page did not respond to that gesture. A freeze report remains unresolved. Motion recording has not been established as working end to end.

The development record reports **590 software checks** for P27. This historical count does not override hardware failures; see [publication checks](PUBLICATION.md) for verification performed on the exported source.

P20 feedback confirmed corrected striped tabs, melodic Euclidean playback and track-colour pad feedback. Later versions continued selection and chord editing fixes. See [KNOWN_ISSUES.md](KNOWN_ISSUES.md) and [FEATURES_AND_STATUS.md](FEATURES_AND_STATUS.md).

The previous public CH10 source remains in Git history. The visual design preview is a separate, later refinement of the P27-based design study.
