# EU8 technical integration

Branch fix/eu8-visible-controls-velocity from EU7 commit 422db63. Restored durable bundle version 13; explicitly imported all its original refs beyond normal clone defaults. No new fixed SRAM, voice/DSP layout, MPU, stack reservation, bootloader/vector/recovery or controller changes. Synth cave 080D5800..080DC000 remains byte-identical to EU5/EU7.

## Proven visibility failures and repairs
Native descriptor constructor 081639A8 creates key 1E5 = Attack, type 20, bounds 1..20. EU7 tried to claim it as Lock condition; the collision guard correctly refused the registry but blocked all custom lock bindings. New keys 198/199 are verified unused after the real constructor. Key 198 is the shifted encoder 3 edit;199 is a consumed/read-only visible Locks when widget on encoder 6. Set native Step-key array 300000BC+4 back to184 (Prob) before every header; EU7 left its shifted key behind. Read title must come from its own registry descriptor because native value override 08170656 calls 08171640, which restores titles from the registry.

Undo text appears in two native menu tables. EU7 changed only FA. EU8 edits F9 and FA. Native 0817818C rejects count>9 even though constructor stores 10 cells. F9 keeps 9 entries: replace blank slot 3 with old Copy, put Select in slot 4, retain all 8 original actions. FA keeps its 4 actions then appends Select as slot 4; change row count from 5 to4. Menu order fills upward within each column: slot 4 is directly right of Undo with four rows. Native 08177D48/0817818C constructors/layout and 08177EE2 action emission are executed in regression tests; same-size, same-y, increasing-x and visible state are checked. Runtime labels update cell 4 in both definitions. Four-byte stack-argument patch 081415F0 is guarded against exact CDF804B0; never patch mid-instruction at15EE.

Tests now construct the actual native registry, actual sequencer widgets/header and native popup application. The old zero-filled registry fixture could not expose the collision, and descriptor-only menu tests could not prove visible placement. Model/GUI-parent routing and XML storage remain controlled fixtures; physical hardware output is not claimed emulated.

## Velocity layer
Encoders 190..193 retain Pad/Length/Hits/Rotate.194 becomes type 7 Vel Mode (10 labels),195 becomes Vel Depth 0..100. Step selection yields to native edit controls; then encoder 6 displays lock condition. Euclidean view-only paint adapter replaces its vtable paint pointer 0819E858, calls original 0816FAEC, and adds five small native-palette rectangles below mode value. It checks context, bank, selected state, descriptor and geometry. No global painter interception or font-glyph dependency.

EuPad remains two words. Existing velocity word now internally packs base bits 0..6, mode bits 8..11, depth bits 16..22; all other bits rejected. Save keeps original word 1 plain velocity for older firmware and adds optional bento_eu2_ROW_PAD_2 (mode) /_3 (depth); existing version 1 retained. Missing fields default Flat/depth0, invalid additions reset safely. M4 publishes through the existing aligned serial; M7 reads the same checked snapshots. No extra shared structure or ownership change.

Generator new-note velocity defaults 100 while native retained notes keep all prior metadata/velocity/locks. Mode/depth edits never call native note mutation/Undo. Legacy programmatic velocity API remains for previous tests/migrations but no longer appears on the Euclidean bank.

M7 reuses the existing once-per-grid native cursor scan. For dynamic pads it counts unique native positions inside that drum's cycle and ranks current position, including manual additions. Bounded16x8 bitmap words live on stack; no heap/audio allocation. Hit index = cycle*hit_count + rank for Alternate/Hits3/Hits4. Rise/Fall/Wave use rank modulo current hit count. Grid 4 keys to step positions. Probability/conditions filter playback without renumbering pattern positions. Changing pattern length/count may change phase; transport reset follows existing Euclidean clock.

velocity.h is pure integer code. At depth 0 or Flat, return exact saved velocity. Other modes interpolate toward available 1..127 headroom, preserving each base velocity at depth 0. Humanize uses a bounded+/-30 shape; Random Accent uses 25% accents against a modest lower background. Both use a local deterministic hash of owner/pad/cycle/hit, changing per cycle without consuming native probability RNG. Legacy unmarked procedural pads also support shapes through bounded pattern ranking; opened pads migrate to native editable patterns as before.

Potential UI/realtime limitations remain recorded in INSTALL and validation. Native cache/deadline/device audio behavior still needs the maintainer's test. Existing conditional record allocation and all earlier project/clip integration limits are unchanged.
